# Tool catalog (i-intelligence Handbook 2018)

Machine-extracted from the *OSINT Tools and Resources Handbook 2018* — **5115 entries** in 19 chapter files.

This is the **breadth** layer: a near-exhaustive directory to look up *what exists* for a given need.
For the **depth** layer — which tool to actually reach for, in what order — use
[`../by-identifier.md`](../by-identifier.md) and the playbooks in [`../../02-playbooks/`](../../02-playbooks/).

> ⚠️ These links date from 2018. Many tools are dead, renamed, now paid, or have changed hands.
> A dead link is still useful as a search term. Never paste case data into an unvetted third-party service.
>
> Roughly 1.5% of URLs (~77 of 5,115) are truncated where the link wrapped across a page
> break in the source PDF. The tool name is intact — search for it.
