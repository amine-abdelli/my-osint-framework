# Glossary

| Term | Definition |
| --- | --- |
| **OSINT** | Open Source Intelligence — systematic collection, processing and analysis of publicly available information. |
| **OPSEC** | Operational Security. In OSINT: not leaving traces that alert the subject or expose the investigator. |
| **Passive recon** | Collection with no interaction with the target's infrastructure or accounts (archives, third-party data, search engines). |
| **Active recon** | Collection that touches the target directly (visiting their site, port scans, viewing a profile while logged in). Higher signal, higher exposure. |
| **POI** | Person / Point of Interest — the entity under investigation. Term originally from the CIA, standard in fraud work. |
| **Sock puppet** | A research persona used to browse platforms without exposing the investigator's real identity. Never used to deceive a data subject into disclosing information. |
| **Pivot** | Moving from one identifier to another (email → username → profile → photo → location). The core motion of OSINT. |
| **Selector** | A single searchable identifier: email, phone, username, domain, wallet, plate, IMEI. |
| **Attribution** | Linking activity to a real actor. The hardest step; endorsement is *not* attribution. |
| **Chain of custody** | The documented history of an item of evidence: who collected it, when, how, and every hand it passed through. |
| **Hash** | A cryptographic fingerprint (SHA-256) proving a file has not changed since collection. |
| **Dork** | An advanced search-engine operator query (`site:`, `filetype:`, `inurl:`). Google Hacking Database (GHDB) is the reference set. |
| **EXIF** | Exchangeable image file format — metadata embedded in photos: timestamp, camera, sometimes GPS. |
| **Reverse image search** | Searching by an image rather than by text, to find prior appearances and original context. |
| **Keyframe** | A representative still extracted from a video, used to run reverse image search on video content. |
| **FIMI** | Foreign Information Manipulation and Interference — manipulative, intentional, coordinated behaviour by state or non-state actors. EEAS terminology. |
| **IBD** | Identity-Based Disinformation — FIMI weaponising gender, sexual orientation, race or ethnicity. |
| **CIB** | Coordinated Inauthentic Behaviour — networks of accounts acting together while presenting as independent. |
| **TTP** | Tactics, Techniques and Procedures — the operationalisation of an actor's behaviour. |
| **DISARM** | An open framework of disinformation TTPs (planning / preparation / execution / assessment). |
| **ABCDE** | Framework: Actors, Behaviour, Content, Degree, Effect. |
| **Breakout Scale** | Ben Nimmo's 1–6 scale measuring how far an influence operation spread across communities and platforms. |
| **STIX** | Structured Threat Information eXpression — JSON lexicon for sharing threat intelligence. |
| **DAD-CDM** | Defending Against Disinformation Common Data Model — STIX extension for disinformation objects. |
| **VLOP** | Very Large Online Platform, as designated under the EU Digital Services Act. |
| **DSA** | Digital Services Act (EU) — platform accountability and systemic-risk regime. |
| **GDPR** | General Data Protection Regulation (EU) — governs processing of personal data, including by investigators. |
| **DPIA / PIA** | Data Protection / Privacy Impact Assessment — structured analysis of data-protection risk before a project starts. |
| **CFAA** | Computer Fraud and Abuse Act (US) — prohibits unauthorised access to computer systems. |
| **Berkeley Protocol** | Standard for digital open-source investigations of international-law violations. |
| **ISO 27037:2012** | Standard for identification, collection, acquisition and preservation of digital evidence. |
| **Public interest** | Revealing information conducive to the common good — distinct from "what the public is interested in". |
| **Infoxication** | Decision paralysis caused by information overload. |
| **Malinformation** | True information deployed to cause harm (e.g. doxxing). |
| **Cheapfake** | Manipulated media made with simple editing rather than AI (recontextualising, slowing, cropping). |
| **Vicarious trauma** | Psychological harm from repeated exposure to distressing material. A real occupational risk in this field. |
| **SiEVE** | Social Engineering Vulnerability Evaluation — a structured process for authorised red-team target profiling. |
