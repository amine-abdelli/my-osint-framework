## Analytical frameworks

| Framework | Domain |
| --- | --- |
| **ABCDE** (Pamment, 2020/2022) | Actors, Behaviour, Content, Degree, Effect — FIMI analysis |
| **DISARM Red Framework** | Disinformation TTPs: planning / preparation / execution / assessment |
| **Online Operations Kill Chain** (Nimmo & Hutchins, 2023) | Asset acquisition → coordination and planning → ensuring engagement → longevity |
| **Breakout Scale** (Nimmo, 2020) | 1–6 impact scale for influence operations |
| **Impact-risk index** (EU DisinfoLab, Miguel Serrano 2022) | Single-hoax impact: low / moderate / high / alarming |
| **STIX** | JSON lexicon for sharing threat intelligence |
| **DAD-CDM** | Defending Against Disinformation Common Data Model — STIX extension for disinformation |
| **Admiralty Code** | Source reliability (A–F) × information credibility (1–6) |
| **ACH** (Heuer) | Analysis of Competing Hypotheses |

## Standards and protocols

| Standard | Scope |
| --- | --- |
| **Berkeley Protocol on Digital Open Source Investigations** (Stover et al., 2022) | Investigating violations of international law |
| **ObSINT Guidelines for Public Interest OSINT Investigations** (2023) | Public-facing, public-interest OSINT |
| **EEAS OSINT Guidelines** (Nov 2024) | Identity-based disinformation / FIMI |
| **ISO 27037:2012** | Identification, collection, acquisition and preservation of digital evidence |
| **OSINT in armed conflict settings** (Millett, 2023) | Legal gaps in IHL/IHRL; conflict-specific harms |
| **OSINT in cases of sexual violence** (Koenig & Egan, 2021) | Dignity, consent, trauma, intersectional analysis |
| **Charter of Munich** | Journalistic deontology |
| **GDPR** | Personal data processing |
| **DSA** | EU platform accountability and systemic risk |
